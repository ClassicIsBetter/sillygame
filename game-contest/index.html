SillyGame Game Contest

SilyGame is doing a game contest!
Here is how to submit your game in to the contest:



  1. Build your game in Roblox Studio (Dont include any scripts)
  2. Go to File -> Save To File As
  3. In the File Explorer popup, Choose "Roblox XML Place Files" then save
  4. Upload it in the SillyGame discord in the channel #game-contest-submissions and follow the post format example
